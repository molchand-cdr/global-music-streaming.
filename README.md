# global-music-streaming.
🎵 Global Music Streaming Preferences Dashboard
🔎 Overview
This project analyzes a large dataset of global music streaming listener preferences and presents insights through an interactive dashboard built with Python (Plotly + Dash). The dashboard highlights how listeners engage with different genres, platforms, and regions, while also exploring demographic and temporal trends.

✨ Key Features
KPIs at a glance: Total listeners, average streams, top genre, and countries covered.

Genre Popularity: Bar chart showing total streams by genre.

Platform Usage: Pie chart illustrating distribution of streams across platforms.

Geographic Insights: World map visualizing listener activity by country and territory.

Demographics: Scatter plot of age vs. streams segmented by genre.

Trends Over Time: Line chart showing how streaming preferences evolve across years.

🛠️ Tools & Technologies
Python – Data analysis and dashboard development

Pandas – Data cleaning and transformation

Plotly Express – Interactive visualizations

Dash – Web-based dashboard framework

🚀 Business Value
This dashboard helps stakeholders:

Identify top genres and platforms globally

Understand regional differences in listener behavior

Track streaming trends across years

Explore demographic insights for targeted strategies
